# Feature4 F4-17 — consume approved VoiceStudio narration without a new mixer

The existing Feature4 `compile_approved_storyboard` already supports signed `voiceover_asset_id` and `voiceover_source=retailer`, with timeline/music/sfx handling. This stacked PR adds only a **trusted private-audio intake gate** that checks a current database-backed `APPROVED_FOR_EDITING` receipt, shop/campaign/asset/request binding, SHA256 of actual source WAV bytes, exact 15/30/60s PCM duration, original tenant storage key, private bucket and approved media rights. It rereads the approval after I/O and then invokes the existing compiler. It neither copies nor synthesizes voice, mixes output, or publishes it.

This branch is STACKED on Feature4 parent PR #322 to avoid shipping a duplicate video engine or changing shared interfaces. Synthetic tests call the actual Feature4 approved storyboard compiler, including foreign-shop/revoked/path/byte-tamper tests. Future integration: parent #322 must be reconciled to main; existing human approval and private worker claims need server bindings. VoiceStudio F2 returns `NEEDS_REVIEW` until a separate trusted review updates the durable receipt; never auto-promote it. Commercial model/rights approvals and real hosted final MP4 still pending. No GPU/paid/PROD/WineShopPOS changes.
