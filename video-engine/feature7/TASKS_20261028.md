## Practical setup for deterministic offline development

- Use the current \`tests/media/test_feature7_pipeline.py\` to synthesize an **original** 16-second 160×288 H.264/AAC test video with 440Hz tone, deliberately silent intervals and a matching tenant-specific in-memory grant. It is an engineering fixture; never market it as a real person/speech.
- A separate WhisperX-shaped word-timed JSON fixture models *already completed* ASR. No ASR model was downloaded or called in this work.
- The private probe checks the exact SHA256 and approved grant, MP4 ftyp signature, ffprobe codecs/duration/audio channels and local root bounds; FFmpeg reads but never mutates media.
- \`private_review_pipeline.mjs\` accepts only server-owned grants and approved local staged media. It returns review-required \`creative_reel_v1\` scene directives with an advisory media digest, audio-activity intervals, original sound preservation, clip-anchored captions and no B-roll network URLs.
- To execute output in Feature4: coordinator must persist real current active membership/rights, review-id and immutable draft snapshot, then recompute the canonical Python \`draft_fingerprint\`, build \`edit_plan\` and revalidate all media. A model/browser cannot set \`approved:true\` by itself.
- Run \`python3 -m unittest discover -s tests/media -p 'test_feature7*.py' -v\` with Node+FFmpeg+ffprobe. The existing \`video-engine/ci.sh\` discovers all \`test_*.py\` files automatically.

## Production exclusions and risk register

This is deliberately **not** a functional production video uploader, real WhisperX inference run, legally approved customer footage, a human audio quality check, SaaS billing readiness, commercial Remotion automation, persisted user approval, new Feature4 renderer, paid GPU deployment or another ad-writing agent.

- A plain JSON string \`issued_by=trusted_server\` is **not a signature**: callers MUST produce it internally only after JWT + RLS + approved storage byte/grant checks. Do not expose this module as unauthenticated HTTP or allow browser to submit grants.
- \`whisperx_json\` is a supplied fixture/input. Its transcript SHA256 records exact normalized words, **not a cryptographic attestation that WhisperX really ran**. The future trusted worker must sign/bind the ASR output to the verified private video bytes and model version.
- Feature4 cannot implement sparse jump cuts while preserving every original scene once. The new code does NOT claim to cut every silence; it proposes a speech-rich contiguous trim and describes residual silence as advisory.
- Real MP4 source may be copyrighted/unlicensed. Never reuse old revoked synthetic retailer assets as production-owned content.
- Current app supports only private image registration. Secure video MIME validation and storage grant/revocation, RLS, signed playback and quotas must be designed in coordinator-owned files, not mocked into production.
- License: AutoBroll MIT notice is retained; no Remotion copied or dependency invoked; third-party commercial automation terms require independent review if ever adopted.
