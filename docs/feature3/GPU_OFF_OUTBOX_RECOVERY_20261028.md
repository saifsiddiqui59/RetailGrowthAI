## 2026-10-29 — Unknown private output settlement fence (source-only)
- `OptionalGPUProvider.execute` now sets an attempt marker immediately before invoking the private output writer. If the Storage stage/readback or one-shot SQL CAS raises or returns an untrusted receipt, **DO NOT automatically call** `finalize_usage(completed=False)` — the write could already have committed. Leave the existing reserved/RUNNING record for independent operator reconciliation of database evidence and actual provider metering, not retry, refund or infer charge.
- Failures **before** any output write (e.g., source-rights revoked after inference) retain the preexisting trusted measured failure settlement; a strictly validated private output plus receipt still permits one successful SQL settlement. Existing one-shot reservation/claim guards are unchanged.
- `tests/api/test_feature3_prepaid_gpu_bridge.py` regression covers timeout after attempted write, forged foreign-shop output receipt, source-rights revocation before write and previously existing successful measured settle. All GPU/media services are test doubles; paid provider OFF. This code cannot itself guarantee operator reconciliation, which remains a separate runtime/observability integration gate.

## 2026-10-29 — Versioned Queue envelope source/receiver handoff
- Added `azure-functions/campaign-api/feature3_gpu_envelope.py` with `encode_dispatch_envelope` and `decode_dispatch_envelope` using the **same exact v1 schema**. The existing `Feature3GPUOutboxPublisher` now uses the shared encoder and rejects malformed/nonrandom IDs BEFORE sending. The receiver decoder is standalone/source-only, bounded to 512 UTF-8 bytes, rejects repeated JSON keys, unknown/excess fields, non-JSON constants, wrong versions and noncanonical UUIDv4 IDs; decoded data contains only `shop_id` and `job_id`.
- The envelope **is never authorization** to invoke GPU or spend. A future backend-only worker must still claim the actual existing SQL job/lease, verify authoritative tenant/source/rights and one-shot reservation, then use the separately reviewed private worker bridge. No Azure queue trigger/paid provider is deployed or enabled by this PR.
- `tests/api/test_feature3_gpu_queue_envelope.py` tests actual publisher encoding, decoder roundtrip and negative input injection, foreign-shaped IDs/duplicate fields/malformed bytes/no queue send. Existing publisher and Azure ACK tests stay enabled.
