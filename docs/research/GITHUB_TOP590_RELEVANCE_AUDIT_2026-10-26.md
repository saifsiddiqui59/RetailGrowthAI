## Major findings (prefer reuse over rebuilding)

1. **Team A:** ComfyUI is the largest useful discovery for a **separate** true generative image/video pipeline. Compare a locally installed/pinned workflow and JSON API to Diffusers/Part 3 provider boundary using mock licensed retailer imagery before any GPU. Do not equate ComfyUI model orchestrator with a novel diffusion checkpoint or assume every workflow fits Azure T4. Retain and compare MoneyPrinterTurbo's complete Docker application, HyperFrames deterministic HTML/CSS motion render, OpenCut's existing stable timeline, Remotion license-eligible alternative. Preserve already-working Azure FFmpeg as fallback.
2. **Team B:** React-Konva still first-fit for narrow in-app poster editing; Penpot is a larger separate design application; tldraw production license is NOT free by default; React Bits carries Commons Clause; shadcn/ui selective components are attractive if compatible with current React 19/Vite. Avoid replacing secure Pillow output.
3. **Team C:** Segment Anything or OpenCV for merchant garment segmentation, Upscayl for image restoration as optional preprocessing, Whisper/whisper.cpp for merchant-recorded footage, and rights-verified stock providers. These do NOT justify downloading unlicensed videos/images or skipping provenance. Cost/CPU/memory benchmark before adoption.
4. **Final Coordinator:** Existing Azure HTTP #249 remains independent blocker for signed-in acceptance. No new third-party social publisher, second tenant store, subscription ledger, platform credentials, unrestricted ComfyUI UI/API, or unapproved WAN API.

## Verified license caveats worth knowing

- OpenCut `LICENSE` MIT; HyperFrames `LICENSE` Apache-2.0; VibeVoice `LICENSE` MIT for *code*; Penpot `LICENSE` MPL-2.0; Coqui TTS `LICENSE.txt` MPL-2.0.
- Remotion `packages/core/LICENSE.md` is **custom**: individual and eligible small company (up to three employees) free, larger for-profit company license and derivative resale restrictions; it is not blanket MIT.
- tldraw `LICENSE.md` is **custom**, permits development but prohibits production environments unless another license/trial authorizes it.
- React Bits `LICENSE.md` **MIT + Commons Clause** permits incorporating components in apps but restricts resale and hosted component/tools offerings.
- Upscayl `LICENSE` **AGPL-3.0**. ComfyUI `LICENSE` **GPL-3.0**. Model weights, bundled voices, media and commercially permissible AI outputs must be separately checked.
