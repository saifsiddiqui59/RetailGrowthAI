# Official platform API research & outstanding checks (2026-10-23)

**Meta Instagram:** official Content Publishing for professional (Business/Creator) accounts; chosen initial path is Facebook Login/Instagram Graph API and Page-linked IG, with reviewed `instagram_basic`, `instagram_content_publish`, Page discovery/permission scopes as applicable. Reels: POST media container -> check `status_code=FINISHED` -> POST media_publish. Confirm media hosting accessibility/duration, effective API version, per-account moving-window limits and allowed content before live integration. Personal accounts are not assumed publishable. Official: https://developers.facebook.com/documentation/instagram-platform/content-publishing and https://developers.facebook.com/documentation/instagram-platform/instagram-graph-api/reference/ig-user/media_publish

**Meta Facebook:** publish Page posts with granted Page access token and `pages_manage_posts` and related Page access/engagement scopes when required. Page-role/access verification and App Review before third-party production use. Current adapter covers Page FEED text, not Reels video. Official: https://developers.facebook.com/documentation/pages-api/posts and https://developers.facebook.com/documentation/pages-api/manage-pages

**LinkedIn:** versioned `/rest/posts` with `Linkedin-Version: YYYYMM` and REST.li header; organic text supports `w_member_social` for authenticated member or `w_organization_social` for authorized Page admin. Community Management access is vetted (development vs standard tiers), restricted `r_member_social` not casually requested. Do not pin a sunset Marketing API version as an indefinite default. Official: https://learn.microsoft.com/en-us/linkedin/marketing/community-management/shares/posts-api?view=li-lms-2026-09 and https://learn.microsoft.com/en-us/linkedin/marketing/community-management/community-management-overview?view=li-lms-2026-08

**YouTube:** `videos.insert` with scoped `youtube.upload`, resumable upload; the upload initialization is not a successful video. Shorts classification is platform determined; enforce video properties and user-selected visibility and synthetic-media disclosure where relevant. Current official docs say projects without verification are not automatically restricted to private viewing, a policy change that must be rechecked before launch; our *default* remains PRIVATE for safety, not because of a claimed mandatory rule. Current quota docs show 1 Video Upload quota unit per upload and separate upload daily caps; do not hardcode outdated 1600-unit claims. Official: https://developers.google.com/youtube/data/reference/rest/v3/videos/insert and https://developers.google.com/youtube/terms/developer-policies

**Cross-provider:** granted scopes, app review/business verification, account ownership, vendor-specific quotas/rate-limit headers, current media constraints, token refresh/revocation and privacy compliance remain **UNVERIFIED FOR OUR APP**. No production OAuth accounts, client secrets, refresh tokens or real posting are active. Any actual platform rate limit may vary by permission tier/account and must be runtime-adaptive.

## Verified official API update (October 23, 2026)

- Instagram official media-publish reference describes up to **50 published posts in a moving 24-hour period** for professional accounts; the account's available publishing quota must still be checked at request time. Reference: https://developers.facebook.com/documentation/instagram-platform/instagram-graph-api/reference/ig-user/media_publish
- YouTube official `videos.insert` documentation (last updated 2026-10-15) currently states a **separate default 100 calls/day** Video Upload bucket with **1 unit per call**, maximum 256 GB and upload scope `youtube.upload`. Treat these as defaults subject to project quotas/policy changes; never guarantee upload entitlement without OAuth consent and audit. References: https://developers.google.com/youtube/data/reference/rest/v3/videos/insert and https://developers.google.com/youtube/data/determine_quota_cost
- LinkedIn official versioned Posts API supports organic text, image, video and documents but actual member/company posting needs granted `w_member_social` or `w_organization_social` and valid author role. Our initial adapter is **text only**, not a claim of supporting those other formats. Reference: https://learn.microsoft.com/en-us/linkedin/marketing/community-management/shares/posts-api?view=li-lms-2026-09
- Meta Facebook official Pages endpoints support Page publishing, not arbitrary personal account posting. Exact app-specific Page scopes, live app review, rate limits and Page ownership must be validated independently. Reference: https://developers.facebook.com/documentation/pages-api/posts
