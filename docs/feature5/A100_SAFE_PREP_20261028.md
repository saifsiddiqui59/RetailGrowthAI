## V100 versus A100
The user's current Azure Container Apps entitlement is **A100**, not V100. Azure serverless Container Apps GPU supports A100 and T4, not V100. All scripts intentionally refuse \`--gpu V100\`. Do not silently substitute a separately billable V100 VM.

Do not deploy an always-on ComfyUI HTTP server or an event/schedule-triggered GPU job for preparation. **Manual job timeouts only bound individual replica execution, not cumulative invoices, networking, checkpoint storage, cold-start or multiple separately initiated runs.** Concurrent manual starts from separate machines may race without a shared distributed lease: coordinator must additionally cap the GPU workload profile to one instance, use the existing spend ledger and issue a single authorized launch.
